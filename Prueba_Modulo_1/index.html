PARTE TEÓRICA

useState es un hook de React que permite agregar y administrar estado dentro de componentes funcionales. El estado representa información dinámica que puede cambiar durante la ejecución de la aplicación y provoca la re-renderización del componente cuando se actualiza.

Se utiliza para almacenar valores como contadores, formularios, datos de usuario o cualquier información interactiva dentro del componente.

Ejemplo:

  • const [contador, setContador] = useState(0);

Un Fragmento en React permite agrupar múltiples elementos JSX sin necesidad de agregar un nodo adicional al DOM. Esto ayuda a mantener una estructura HTML más limpia y evita elementos innecesarios que podrían afectar el diseño o el rendimiento.

Se representa mediante la sintaxis <></> o utilizando React.Fragment.

useState: se utiliza para manejar estados locales dentro de un componente específico. Su información solo afecta al componente donde fue declarado.

useContext: permite compartir datos entre múltiples componentes sin necesidad de pasar propiedades manualmente, facilitando la gestión de estados globales como autenticación, temas visuales o configuraciones generales.

Un componente funcional es una función de JavaScript que retorna código JSX, el cual describe la interfaz gráfica que React debe renderizar.

Puede recibir propiedades (props), manejar estados mediante hooks y ejecutar lógica antes de renderizar la vista.

Ejemplo:

  • function Iniciar() {
      return (<h1>Hola Mundo</h1>);
    }
